# Melting Point Chronicles 🔥

A Nigerian secondary school anime RPG — web prototype. Play as Michael (or 7 other characters), explore Melting Point College in Port Harcourt, build your Aura, interact with NPCs in Pidgin English, and unlock the secret of the school.

## Tech Stack

- **React 19** + **TanStack Router** (file-based routing)
- **TanStack Start** (SSR/SSG via Vite)
- **Tailwind CSS v4**
- **Canvas API** (game engine)
- **Netlify** (hosting)

## Pages

| Route | Description |
|---|---|
| `/` | Landing page with hero, features, aura system, story chapters |
| `/avatar` | Character selection (7 playable + Isi Owu) |
| `/game` | Playable canvas RPG prototype |
| `/gallery` | Full character art gallery with lightbox |
| `/how-to-play` | Controls, systems, mini-games, endings guide |
| `/roadmap` | Development timeline and upcoming features |
| `/about` | Full cast, creator message, game credits |

## Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
