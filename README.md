# Melting Point Chronicles 🔥

A Nigerian secondary school anime RPG — web prototype. Play as Michael (or 7 other characters), explore Melting Point College in Port Harcourt, build your Aura, interact with NPCs in Pidgin English, and survive the chaos of school life.

## Tech Stack

- React 19 + TanStack Router
- TanStack Start
- Tailwind CSS v4
- Canvas API
- Netlify

## Pages

| Route | Description |
|---|---|
| `/` | Landing page with hero, features, aura system, story chapters |
| `/avatar` | Character selection |
| `/game` | Playable canvas RPG prototype |
| `/gallery` | Full character art gallery |
| `/how-to-play` | Controls, systems, mini-games, endings guide |
| `/roadmap` | Development timeline and upcoming features |
| `/about` | Full cast, creator message, game credits |

## Run Locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.
